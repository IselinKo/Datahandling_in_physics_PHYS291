In this exercise, you we first warm up by working with GUI - learning how to fit a histogram
with the help of graphical tool Fit Panel (part 1). There is a movie demonstrating what to do,

Next (part 2) we learn about various types of scripts (macros) - the small root
programs. There are unnamed (nameless) and named scripts, which contain a function
of the same name as the file itself.
Further (part 3) we shall try in root command some basic programming features,
i.e. conditions and loops, the most basic elements of any code.
Next (part 4) you will explore some data types in C++, numerical, logical, strings.

For those who do not drink this will become a general membership discount problem.
(We keep both tasks - with the same parameters)
Your challenge is to develop a small script (e.g. by modifying an example)
At the end (part 7) there is a short exploration section on histograms vs plots of functions
and how to relate them (histogram -> to graph)
During all this you will also try several short C++ and ROOT programs.
Please try to keep the indicated times for each part.

Part 6 is the most important, since it is your first really independent work.
There is also an additional demo of how to write a function simplifying
adding the axes labels, as well as the method gROOT->ProcessLine(".q") etc

file labels.txt
