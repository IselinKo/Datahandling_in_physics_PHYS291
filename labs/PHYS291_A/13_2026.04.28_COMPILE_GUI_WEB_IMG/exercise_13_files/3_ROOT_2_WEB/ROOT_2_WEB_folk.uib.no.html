WHY THIS:  It should be helpful in your design of your report.

In short, this package demonstrates how one can use a root script and simple shell commands
to construct a web site served by a local webserver, with LaTeX math and animated content
Some of you are experts - then just look at this little demo.
It is a bit fun ...

A SHORT WHAT IS THIS?

A root script makes a webpage showing plots-examples

It also shows how to use LaTeX formula - for that one usually needs
the assistence of a webserver - thus the root script via

system(command)

starts a local webserver.

Sources, comments and video are shown.

IT IS RECOMMENDED THAT YOU DOWNLOAD  ROOT_2_WEB.zip to a linux
or macOS machine with root and some of our bash-scripts (present in your bin/ directory)

unzip

cd ROOT_2_WEB

make

(cf the video)

Note that the " system (command)  " calls are also listed explicitely

unzip ROOT_2_WEB.zip - cd to ROOT_2_WEB and type     make
