Tribute to John Conway
Game of Life in simple ROOT Scripts

life2.C     one "glider"
life3.C     two gliders - nicest
life1.C     random population, shows how many remain

updater.C   the mechanism for screen is taken from there
            Try this - can be useful

works on most terminals, but on some the colors do not show
e.g. on windows in some cmd.exe only the crosses in black/white show

The nlife0.C  nlife1.C	nlife2.C  nlife22.C	nlife3.C
are variants with blocks instead of crosses (try root nlife0.C)
