Exercise 7 Task

Note that below in this description file there are proposed more advanced forms
of the solution where a program (function) fetches automatically the histogram names.
In example files this is demonstrated and the scripts/macros contain extra features
which can be used, as shown further in text.
Here is the original text of the exercise, simple and straightforward.

 

Three student groups in Bergen, Oslo and Cambridge measured
energy of alpha particles from the same type of alpha source.
Their three detectors had different backround noise and the
experimental widths also differ a bit.

Your task is to inspect the three histograms contained
in the three root files, make a fit for all three
using the single Gauss on a linear background.

The methods are simple modifications of the examples
p2_hist_fit.C provided in the in the zip-file.
The root files are
Bergen.root      OSLO.root   cambridge.root
extended last year by 3 more
Paris.root      Roma.root    berlin.root

The names of the histograms inside the files are different. You could use
the TBrowser or the TFile ls() to find their names manually.
There is however a script/macro called find_histograms.C (in 2 directories)
which prints the filenames and histogram names and even plots them.

The straightforward method (not recommended for submission) is to take the provided
p2b_hist_fit.C (modified for Bergen and copy to p2c_hist_fit.C and p2o_hist_fit.C
for Cambridge and Oslo etc ). The 2026 version is modified to append automatically
output of the fit parameters to file report.txt.
In many exercises we have done the "print to PNG-file" copies of canvases.
You should select and include a collection of fits of the type shown below,
perhaps named as the root files, i.e. Bergen.root has Bergen.png etc.




One of the output windows of the script p2_hist_fit.C
It shows the fit to the peak with the background subtracted.
It is done simply by setting the background parameters to zero.


This is the canvas showing the FWHM (full width at half maximum )
constructed by the script extragr_p2.C
when applied after any of the versions of p2b_hist_fit.C
