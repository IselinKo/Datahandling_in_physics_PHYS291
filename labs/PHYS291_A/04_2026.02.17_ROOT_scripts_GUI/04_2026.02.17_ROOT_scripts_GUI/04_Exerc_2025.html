How to work, really only copy-paste? TAB-completion in ROOT; Using .root_hist
Note: when suggesting "copy line by line into root" - what that really means is:
(1) have a good look at the text, the line to be copied as well as its neighbors
(2) copy the line - or only its part if you wonder about its form or other details
(3) paste it in the root window. Then hit "Enter" or edit before that Enter
(4) sometimes the root engine will ask you questions, e.g. if your entry is part of something
(5) sometimes root can suggest things if you hit the "TAB" key (looks often like -->| )

In most of the examples points (4) and (5) are not important, unless there is a "loop",
like in

the root window will look like this

and you just continue pasting the following lines, basically ignoring the message
(cont'ed, cancel with .@) in the root prompt until it disappears when the element is complete.

About point (5) above - the TAB: You have defined a longer name, e.g.

Using .root_hist to recover what you entered in root command

When testing, editing - one can use the .root_hist file in your $HOME directory
Have one more terminal - pwd at your home directory
Type cat .root_hist             Enter
                that will show you all your entries
Unlike the .bash_history which is updated only after you exit the shell
.root_hist is updated after each entry in the root command window ! Try that!

Note that if you run multiple root sessions, their inputs will be mixed !

This can save lots of time. When things go wrong, exit root, start again
and enter the part from history up to the (last?) problem input.
In the "history terminal" just "arrow up" the command
cat .root_hist
                ... in addition to using a text editor to continue with your script ...

6. ROOT tutorials - Method B: The web - CERN

On the root pages (root.cern.ch, documentation -> tutorials),
there is a lot of tutorials like the one you already tried above and
also will find copied below in a newer version -
a simple graph of a sine function.


You can simply search Google for root graph.C tutorials

Unfortunately, the documentation in most recent versions is now very fancy
and it is difficult to extract directly the actual source (and broken links)

So the file
https://root.cern.ch/doc/master/graph_8C_source.html
is beautiful to see and read, but there is no easy way to get the actual source
(because the of the line numbers mix in)
However, going to the file documentation
https://root.cern.ch/doc/master/graph_8C.html
you will see both the output (graphics) and the listing
in a simple form, easily selected and copied (no line numbers).

Run gedit and copy the file content to your local graph.C in a directory
you work. Then run terminal -> cd to this directory -> run root graph.C

REMEMBER: the program inside and the file must have the same name
