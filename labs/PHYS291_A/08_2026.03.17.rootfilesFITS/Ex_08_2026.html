PHYS291 - Exercise 8 - Week with 17.03.2026
Fitting of histograms and also graphs; From files; With two peaks;
Script-based work on multiple files and objects. Assignment hints.


This week we explore automatic processing of several histogram in one file, selection of histograms
from a collection of other objects in the root files - and designing the root macro/script to keep
access to all the functions, fit parameters etc.

This year's version follows last year, but with an extended functionality.
It is a demanding project, you might need more help than usual, however in some way it gives a taste
of a "real work" with modification of existing codes/scripts.
Please do ask questions!

The task last weak was to work with fitting of histograms stored in several root files. The idea
was to make a simple collection of scripts each working on one root file and then combining them
into one code. This time there are many histograms in one file and the stress is on putting this
all in one file. In the files provided with the Assignment this is shown in several versions.
Therefore we add the Assignment/Histogram Part files to the files of this exercise.

The histograms we work mainly with this week have two peaks so that the fitting functions are
somewhat more complex.

The fitting of histograms is most usual fitting type in our root examples. However, to fit data
which are presented as functional dependence, i.e. graphs, can be also done. We have
a demonstration of this, since that can be very useful for some of your projects.

In the previous exercise the fitting of many histograms involved manual listing of the stored objects.
Root provides lots of mechanisms to do this automatically, where a functions "looking in the files"
for you can provide the names types and of the objects.
This can have many variations - thus there are many possible examples and some of them are
included here, mainly as demonstrations which you should explore.
In the examples from the Assignment this is also shown - and the scripts work nicely

The topics are fitting histograms with two peaks and working with
batch processing - or script-based (automatic processing) of many histograms.
These can be in many files, perhaps one per each file, or many histograms in
a single file. Or - what if the files contain also other objects?

We start (see links above) by showing that also points in a graph (not only
in histograms) can be fitted in a very similar way as in histograms.
Here you should try to aply the same treatment to a different mathematical function
by simply modifying the provided script/macro. Note that here you will meet also
the random number production.

In the following part there is the main task - process many 2-peak histograms
stored in a root file.
This exercise is sort of continuation of Exercise 7. In a way it repeats
all the steps there, but now we work with 2 peaks histograms.
Further, the root-file methods (member functions of TFile) to list and
process objects stored in files are explored.

This text contains also additional material, including much of the 2018 version,
with added extra parts collected in the indicated directories.

The main task is in the directory 2_LOOP_to_FIT
