In your task - producing loop_fit.C from one_fit.C
Some of the object pointers in one_fit.C are already made to be arrays, 
some names refer to just one pointer - and those changes are your task.
(example: there is   
                TF1 * plotfun[6];  done - but also  
                TF1 * tryfun;      your task to change)

A special feature are the parameters, the array of parameter values.
Each of the function objects carries "their own" parameters inside itself,
but the array   nparams[ ] is used to enter them, as in  twogaus->SetParameters(nparams);

We recommend in here that since there will be twogaus[k]  we also use
   double array nparams[k][ ]      leading to  twogaus[k]->SetParameters(nparams[k])
For setting the parameters (before fit) a single array could be used (objects keep them)
but it will be useful for a feature that you should include:
   after the fit, the resulting parameters should be placed back to replace the 
   starting values    

This is rather complex work, so we have done it for you; 
       this double array nparams[ ][ ]
       is already present in this 2025 version of one_fit.C
