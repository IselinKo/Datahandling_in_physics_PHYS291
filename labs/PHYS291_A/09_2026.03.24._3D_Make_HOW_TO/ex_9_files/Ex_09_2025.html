Introduction to Earlier version - The History Only?     List of Links to Ex.9 topics

This exercise is based in some parts on exercise sessions in the week
which started 16.03.2020, the first exercises after the COVID lock-down and thus all
exercise work could be done ONLY via network - and text terminals only with no direct
graphics access via the X-window protocol.

The following week in 2020 we already started using the open source based mobaXterm and
thus got back the graphical connection, though for some purposes somewhat slow.
The crisis solving trick we used in this exercise in 2020 was to show the graphics
via our webserver folk.uib.no - based on the access to the server via the login.uib.no.


Now we do not need this, but for our course it still remains an interesting application
of the network, html etc. And for you as future specialists it is useful to know how
one can try to handle the crisis.
Thus in several places in this text we keep the this 2020 two-terminals two-machines
technique in the mainly unchanged form. You can use it - or just test the html production
locally i.e without placing it on the server. We shall also try to do a real time updating
and browser update as a demonstration.
Unfortunately in 2025 the server is NOT available!
We will try to simulate this on our xklient 10 local server
