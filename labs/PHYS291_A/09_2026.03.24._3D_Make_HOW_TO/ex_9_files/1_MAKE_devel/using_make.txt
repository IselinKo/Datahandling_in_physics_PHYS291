
An important part of software developement - automatic
production - compilation - of programs or documents

Utility make - standard on Unix   

Makefile: contains entries - what to make and how

make all   - the standard for all programs
make all is the same as simply
make 

label "all" must contain all the "products" to be made

IMPORTANT - what triggers any of the steps?
            dependence   - C_comp needs only be compiled
                           when comp.c  has changed
                  ( test it, just add a blank line or similar )

VERY IMPORTANT:  all the executable lines start by TAB (not spaces)
from our example - there is a TAB before gcc - and nothing happens
before comp.c has been flagged as modified

C_comp: comp.c
	gcc -o C_comp comp.c

it is usual to have label clean - removing all the "products"
and e.g. label test.

HOW TO USE - test this
========================
make                            produces the indicated elements, files, documents
make clean                      you write in a command cleaning whatever you need
make test                       run it and see
