1. From struct to class

Last time we worked with structures, mainly rather abstract type.
In this part we start with the class concepts - by first explorting
a very simple structure - student - see a_student_struct.C

In a_student_struct.C the structure is shown (the first 5 lines).
In the rest of the file there are defined some functions to work
with the structures. It is possible to access all three members,
name, course and mark.

The same structure is made to a class in file b_student_class.C .
The members of the structure (class Student) are private, it means
they can be accessed only via the public functions.
Why this - because the functions may be equiped with checks of the
integrity of the date (see the condition on length of the name
as an example).

The files c_student_defs.C and d_student_comments.C are variants
of the same class. Note the difference, these are generally two alternative
ways to specify the classes; note the Student::Student() in the last 2 files.

Examples for you to explore are in file 0_examples.txt . Go through
all the lines of the file.

Your task is to provide the missing functions, indicated
(see: Missing functions: SetMark(char m) string GetCourse() char GetMark()
at the end of the file)

Do this, i.e. modify the file b_student_class.C to have these missing "methods".

2. Work with classes (following the lectures)

There are two parts in this topic: The class Time and the class mammal with derived dog and cat.
In the Time case we work with the overloading of operators
In the mammal case we work with so called inheritance, i.e. with derived classes,


In the mammal case the C++ files contain the headers and implementations, all always in one file.
The files are so constructed that they can be both compiled and run in root without
any modifications needed.
Illustrated are the replacement of "private" by "protected" and the "virtual" attribute for
functions (methods) which are going to be modified in the derived class

There are detailed descriptions in the provided files.

In the first case, the Time class, there are provided specialized root files, as discussed
in the following file (also here are detailed descriptions in the file package)
