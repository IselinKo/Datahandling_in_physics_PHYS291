
Additional comments on TNtuple and TTree objects

TTree is the most important object type for data storing in root files.
Lots of particle physics data exist i the form of root files.
We have used root files also for storing histograms.

This is about TTree objects and related TNtuple objects

TNtuple is defined with names of "branches - example x y z here
It can be simply "Fill()"-ed - just like histogram

In addition, it can be filled from a file

TNtuple * extuple= new TNtuple("extup","Example ntuple","x:y:z");
float x,y,z;
extuple->Fill(x,y,z);
extuple->Fill(1,2,3);
cout << extuple->GetEntries() << endl;


int nlines;
//  TNtuple * extuple= new TNtuple("extup","Example ntuple","x:y:z");
nlines = extuple->ReadFile("exampl.txt","x:y:z"); 
//   it turns out that for TNtuple, you can write extuple->ReadFile("exampl.txt");

cat exampl.txt 
12.0  4.0   6.0
1.0   1.9   2.0
3.0   4.0   5.0

extuple->Fill(x,y,z);
nlines = extuple->ReadFile("exampl.txt","x:y:z");  // adds 3 lines
nlines = extuple->ReadFile("exampl.txt");          // adds 3 lines
extuple->Fill(x,y,z);                      // adds 1 line

extuple->Print();     // diagnostic info

TTree is much more flexible - and therefore requires quite complex description
The ROOT documentation must cover all the possibilities - and therefore can not
be "pedagogical"
We can not explore all the functionality of TTree objects. 

Most important for us is that there is not such a simple and compact defining 
statement as for the TNtuple
TNtuple * geotuple= new TNtuple("geotuple","Example ntuple","alt:posx:posy:time:valu");

No, for the TTree there is only possible this:

TTree * ExTree = new TTree("ExTree","Example TTree"); 
There are no other possibilities, just simple object initialization.

The "branches" must be defined each by one statement, which specifies also
how they can be filled. This by specifying an ADDRESS from where to fetch the 
data.

There is one exception - for a very simple tree which basically is like the
ntuple
//  TREE using TTree::ReadFile(filename) i.e. extree->ReadFile("example.txt")
TTree * ExTree = new TTree("ExTree","TREE using ReadFile(filename)"); 
nlines = ExTree->ReadFile("exampl.txt","varx:vary:varz");
// could be also ExTree->ReadFile("exampl.txt","a:b:c"); for example
// unlike for TNtuple where the varable names MUST be included

For all other cases, it must be done as in the examples.
The "good news" is that the things which can be put into the branches
are all from simple numbers, over character strings to complex objects
or structures.

This is shown in the examples 
make_TTree.C, make_charTree.C  ( grow_TTree.C  adds to extra data )

The branches are defined before the filling can start by
float PPx;  char Names[50];
tch->Branch("str",Names,"str/C");  
tch->Branch("px",&PPx,"px/F");
//     If all the variables are assigned the wanted values, fill the tree
tch->Fill();

The opposite process of fetching the data from the tree after it has been
fetched from the root file is done like this:

float PPx;  char Names[50];  //   as when filling
                             //   Branch replaced by SetBranchAddress
   tch->SetBranchAddress("px",&Ppx);
   tch->SetBranchAddress("str",Texts);  //  Texts is a pointer

tch->GetEntry(i);       // this is usually in a loop for(i= ;i< ;i++)

Details are illustrated and can be understood from the files
