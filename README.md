A project for PHYS291 - Data Handling in Physics. 

The aim of the project is to utilize CERN's software framework ROOT, written in C/C++, to explore and visualize our dataset of choice. 

As preliminary work for my master thesis, I chose to analyze resting-state fMRI data. All plots were created using ROOT

In the directory "Project submission" there is a README with further instructions for how to run the project.
