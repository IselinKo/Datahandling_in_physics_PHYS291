The root script  
                    root_to_webN.C 

makes some images and presents them in the index.html
prints the text and formulas in $$ latex syntax $$
creates some links in the index.html

explore this macro/script, especially the system calls
(they are simply linux commands - starting programs, making index etc)
Use of local python webserver
       why:   static html can not use MathJax for the latex
              also, applying this in your project will unify the submissions
              restores the use of webservers as a part of the PHYS291
Use of our programs  txtbox_white  etc  to insert code
       Because of this you can run this package on our machines only
       unless you fetch to and unzip at your private/outer linux/mac
       you need root anyway

This demonstration is run by   Makefile   so that
in this directory you type

     make 

when you are done, you can type

     make clean

or you can just stop the webserver by

     make stop

which add the html code in text-field to be viewed as the source
