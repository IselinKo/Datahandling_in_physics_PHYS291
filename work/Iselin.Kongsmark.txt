In this project for PHY291, I will visualize fMRI data representing brain activity in the Default Mode Network (DMN).


About the data and the preprocessing steps

The raw data is stored in a NIfTI (.nii) file, with dimensions x, y, z, and t, forming voxels containing activity levels over time. Using the Python package NiBabel, the data will be sampled and converted to a text file (CSV). Sampling is performed to reduce computational time and processing requirements while still retaining sufficient data quality for visualization purposes.

The CVS text file will further be converted into a ROOT file, which will serve as the main data format used for this project. 


Visualizations

The project will consist of two main visualizations: one with constant time and varying spatial coordinates, and another with constant spatial coordinates and varying time.

1. Vary z with constant t

Two-dimensional histograms of brain slices will be generated, where color represents activity level. x, y, and t coordinates will remain constant, while z cordinate increases for each new plot. This will create the effect of “scrolling” through the brain volume, similar to the visualization used in CT imaging.

2. Vary t with constant x, y, z

A three-dimensional visualization will be created to display how activity changes over time. The user to be able to choose the x, y, and z cut-off points before plotting. Depending on the time available for the project, the user input will either be provided through the terminal or through a graphical user interface.
