Extending the derived classes - inheritance of features

The main point here are the keywords
"protected"  instead of "private"  and
"virtual"  for the functions (methods) 

The original class is "Mammal", the derived classes are 
"Dog"  and "Cat".

Here are some example what to try in root

   Explore the Clone  and  copy by = ( assignment )
   ( c.f. the "shallow copy"  )

=============    do this in root =======================
.L mammals2017org.cpp 
//   Spot is "born" as a regular dog
Mammal *Spot=new Dog()  //  assigned to Mammal pointer
Dog * Spotty =new Dog() //  Spotty is a Dog * Dog
Spot->Speak()
//  Clone Spot  - to Fido ; Fido is a regular dog
Mammal* Fido=Spot->Clone()
Fido->Speak()
Dog* Thunder = (Dog*)Spotty->Clone()  
Thunder->Speak()
//  Hero is a dog made as a copy of Spot by using =
//  This is called shallow copy
Mammal Hero = *Spot;
//  Hero does not bark!!
Hero.Speak()
//  here a comparison
cout << "Spot sounds: "; Spot->Speak(); 
cout << "Fido sounds: "; Fido->Speak();
cout << "Hero sounds: "; Hero.Speak();

cout << "Fido's age: " << Fido->GetAge() << endl;
cout << "Hero's age: " << Hero.GetAge() << endl;
