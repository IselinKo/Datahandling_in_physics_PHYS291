===========================================================
Extended the derived classes - inheritance of features

This exercise should help you to get some understanding of
so called inheritance, i.e. making classes which 
extend the structure of the original classes.

We use an example from a book, which is not very elaborated,
but contains several features which one can meet in work
with real life cases.

The original class is "mammals", the derived classes are 
"dog"  and "cat".

The main point of the original examples are the keywords
"protected"  instead of "private"  and
"virtual"  for the functions    
(if virtual not present, the "voice" method can not be modified)

Tasks: 
1. explore the four cpp versions 
   Use the make utility - see what will be produced
   (four executables, two text files from running the test)
   

   What are they doing and what are the differences?
   How to run in root and how to compile is indicated
   in the comments in the beginning of the three cpp files

   In addition to running the whole scripts in root, you can
   also start by  .L scriptname.cpp
   and continue by typing in extra lines of code

   Here is one example what to try in root
   Explore the Clone  and  copy by = ( assignment )
   ( c.f. the "shallow copy"  )

=============    do this in root =======================
.L mammals2019org.cpp 
//   Spot is "born" as a regular dog
Mammal *Spot=new Dog()
Spot->Speak()
//  Clone Spot  - to Fido ; Fido is a regular dog
Fido=Spot->Clone()
Fido->Speak()
//  Hero is a dog made as a copy of Spot by using =
//  This is called shallow copy
Mammal Hero = *Spot;
//  Hero does not bark!!
Hero.Speak()
//  here a comparison
cout << "Spot sounds: "; Spot->Speak(); 
cout << "Fido sounds: "; Fido->Speak();
cout << "Hero sounds: "; Hero.Speak();

cout << "Fido's age: " << Fido->GetAge() << endl;
cout << "Hero's age: " << Hero.GetAge() << endl;

=============    root session end  =====================
