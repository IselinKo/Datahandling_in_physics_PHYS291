This is a set of files illustrating the class/object and relation to struct of C/C++
and how these interpreter versions can be (with minor changes) made to C++ compiled
versions at the end

In the L_C_PY_CLASS/  we go from Python class to C-struct to C++ class 
                    with public members only; no private members

In CPP_methods/   type C++ class from above gets also constructors and methods
                  and the typical division into the 3 files is also shown
                  all this is done in ROOT 

in Gplusplus/   - refers to the g++ compiler; mainly same code as in CPP_methods/
                  BUT COMPLETELY without the interpreters; compiled version!


L_C_PY_CLASS/
│
├── STRUCT_CLASS/       structure to class, struct(C) vs class (python)
│   ├── studs.py             python   class            python3  studs.py
│   ├── studs.C              root C   struct           root  studs.C 
│   ├── studs.cxx            root C++ class            root  studs.cxx
│   ├── studsA.C           - studs.C    printing also size of one struct storage
│   └── studsA.cxx         - studs.cxx  printing also size of one object storage
│
├── CPP_methods/        class from  studs.cxx   with methods and constructors
│   ├── studgr.C             single file class definitions, main script, methods
│   ├── studgr.CPP         - first of three conventional files dividing studgr.C   
│   ├── studs.h            - the headers - class definition, methods prototypes
│   └── studs.imp          - implementation of the method functions
│
└── Gplusplus/
    ├── studgr.cpp       - contains  studgr.CPP of ROOT made to COMPILE
    ├── studs.h          - the headers - class definition, methods prototypes
    ├── studs.imp        - implementation of the method functions
    └── Makefile         compiles; run as ./studgr

In CPP_METHODS/ we use C++ strings, while in studs.cxx we use C-string char [ ]
In Gplusplus/ the "void studgr()" of studgr.CPP from CPP_methods/ 
   is replaced by "int main()"  in studgr.cpp (also added using namespace std)
