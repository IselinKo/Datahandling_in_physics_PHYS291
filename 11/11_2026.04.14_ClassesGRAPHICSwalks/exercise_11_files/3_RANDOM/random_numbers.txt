Random Numbers
============================

There are several Random Number Generators which can be selected.
We are going to use just the default one this week

gRandom  is root's pointer to the generator
it is TRandom * gRandom; it is implicitely declared (do not do it!)

gRandom->Rndm() returns a random number between 0 and 1 (try it!)

Unless you do something, the sequence is always the same
Try:
root
cout << gRandom->Rndm() << " "<< gRandom->Rndm() << " " << gRandom->Rndm() << " " <<endl;
.q
You see - allways
0.999742 0.16291 0.282618 
root
cout << gRandom->Rndm() << " "<< gRandom->Rndm() << " " << gRandom->Rndm() << " " <<endl;
.q
 To get allways different sequence, you must add gRandom->SetSeed();
root
gRandom->SetSeed();
cout << gRandom->Rndm() << " "<< gRandom->Rndm() << " " << gRandom->Rndm() << " " <<endl;
.q
